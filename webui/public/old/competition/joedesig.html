    My Report    

My interface design is intended to make the robot more user friendly. By doing so I needed to think how the beginner and expert would use the interface. I also had to take into consideration that people (especially on the Internet) have very short attention spans. Other things came into play like the user's bandwidth and screen size. Overall, the design is to the liking of my small test group.

The short attention spans of Internet Web users are very short. They like to click, click, click. The amount of reading done is minimal. I tried to put the most important information at the top of the page to catch the user's attention. Also I put important information in bold. This will catch the user's eye. This was only done on the new operator page because that is where the user will be getting the needed information for the first time. I also added the same information on the next pages, but this time lower down. When I moved the information, I moved it along with other blocks of information. This allows the user to easily find anything at any given time. The ability to look up a spec of information is important; each block of information has been set off and easily visible.

I also didn't want to have the user scroll. This slows down the response time. The input boxes for movement were placed as near to the images as possible. The advanced user may know the commands, and therefore may go ahead and type in a set of moves right at the top. This greatly reduces the amount of time taken on each move.

Many of the unneeded components were done away with or shrunk. The communications console took bandwidth and cpu time to load. On computers with lower bandwidth it interfered with load time of the important images. On slower computers, the Java took time to load and therefore the user was bogged down. A link was added to fix this problem.

In conclusion, I have designed an interface that will be suitable for both the expert and beginner. I believe that it will increase the response time of the users.
