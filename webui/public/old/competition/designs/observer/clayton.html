Basic robot informaion

The robot positions are in mm and angular position is in degrees. Movement values increase going right (X), away (Y) and up (Z). Currently the robot is being operated by another user, however, if they don't make a move within 3 minutes, the robot is available to a new user. Clicking on 'Try to get control' will attempt to gain control of the robot and/or update the image if a newer one exists.
