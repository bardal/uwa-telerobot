UWA Telerobot help

Quick start

  1. Press Control Robot (Robot panel, top left). The Controller line shows your nickname.
  2. Drag the yellow cursor in a camera picture to where you want the gripper.
  3. Right-click the picture and choose move robot to cursor.
  4. Watch the robot move; the pictures update when it stops.
  5. Press Release Robot when you've finished, so someone else can have a go.

Taking control

  • If nobody is driving, Control Robot gives you the robot straight away, guest or not.
  • If someone else is driving, you can take over once they have had it for 3 minutes. A registered user can take over from a guest at any time.
  • When you lose control the button changes back to Control Robot and the console says who has it now.
  • Closing the page gives the robot back. So does leaving it: you are disconnected after 10 minutes without doing anything, and after 2 hours in any case.

Moving with the cursor

The yellow stick drawn over each picture is a 3D cursor: it is the same point in all three cameras, so you can line it up in one view and check it in another.

  • Drag the bottom marker or the plumb line to slide it across the table.
  • Drag the top marker to raise or lower it. The plumb line runs down to the table so you can see the height.
  • Drag the spin needle (the one with the square tip) to turn the gripper, and the tilt needle to tilt it.
  • The part under the mouse turns red. The cursor's position is shown in red at the top left of the picture.

Right-click a picture (or Ctrl-click on a Mac) for the cursor menu:

ItemWhat it does
align cursor with robotMoves the cursor to where the gripper is now.
set cursor to homeMoves the cursor to the home position.
set cursor to pointMoves the cursor to the selected workspace point (see Points).

Typing commands

The Command editor takes a path: a list of waypoints separated by ;, each setting one or more axes separated by ,. Press Send command to run it. Axes you leave out stay as they are.

AxisMeaning
x y zGripper position in mm. The origin is the grid corner where the red and blue edges meet; the grid runs 0 to 600 in x and y; z is height above the table, 5 to 450.
sSpin in degrees, -270 to 90; the robot starts at s-90. Easiest to set with the cursor's spin needle.
tTilt in degrees, -60 to 60, or tf / tv / tb for forward (-45), vertical (0) and back (45).
g0 / g1Open / close the gripper (also gopen / gclose).
rBefore an axis: relative to where the robot is, e.g. rz-20 moves down 20 mm.

Example: pick up the red cube and put it on the blue one.

x120,y150,z60,s-90,t0,g0;z15;g1;z80;x330,y120;z45;g0;z90

The Robot menu can write commands for you: Command from cursor, Command from selected point, Open/Close gripper and Generate Random Move add a line to the editor for you to check and send. Clear empties the editor. A move outside the limits above is refused and the Command Status line says why.

Picking up blocks

  • Open the gripper, lower it around a block, then close it. The fingers close until they touch.
  • It only grips with the tilt within ±20°, and with the block between the fingers along their spin. A block 30 mm wide fits easily; one wider than about 65 mm won't.
  • Opening the gripper drops the block onto whatever is below it. A bar can bridge two columns; nothing stacks on a roof.
  • The table has cubes, bars, columns, roofs, arches and cylinders. While you're in control, the Robot menu can Add Block (up to 20), Randomise Blocks (lay them all out at random) or Reset Blocks (back to the standard table). Put down anything you're holding first.

The cameras

  • Choose Colour, YCam or ZCam above the picture. Colour looks from the front, YCam from the side and ZCam from high above.
  • New Image takes a fresh picture now. Pictures are also taken after every move.
  • Change width, height (up to 768 × 576) or quality (1 to 50; higher is sharper but slower to load), then press Change Settings. The settings are shared: everyone sees the change.
  • zoom and fixed are kept from the 2000 cameras; they don't change the pictures.
  • The blue line over the pictures is the path the gripper has travelled. Clear it with Images → Clear Path.

Points and measuring

  • Workspace points are named crosses that everyone can see. Add one with Workspace → Add Point (name and x, y, z). Click a cross to select it (it turns red); the selected point can then be used by the cursor menu and the Robot menu.
  • Measure point: click the same spot in two different camera pictures. The second click works out its 3D position; after the first click the other camera shows a green line the spot must lie on.
  • Measure line: measure two points that way and it gives the distance between them.

Chat, history and limits

  • Type in Message at the bottom to chat with everyone connected; Users lists who's here. The Console shows what the robot and the system tell you.
  • Chat, moves and pictures are public and kept in the archive; see History.
  • The lab sleeps when nobody has used it for 15 minutes. The first visitor after that waits about a minute while it starts.

The interface is a copy of the Java applet the University of Western Australia's telerobot used in 2000. The robot today is simulated, drawn to the IRB 1400's real dimensions.
